## Open-Source Projects

### [EntraTopology](https://github.com/0xDarknightHacks/EntraTopology)

A read-only Microsoft Entra inventory and topology engine for understanding **what exists, how objects are connected, and what changes over time**.

It collects tenant state into portable snapshots, builds an explorable relationship graph, adds evidence-backed security context, and supports offline exploration and semantic change monitoring.

**PowerShell · Microsoft Graph · Entra ID · Topology · Change Monitoring**

### [Entra Object Inspector](https://github.com/0xDarknightHacks/EntraObjectInspector)

A read-only, evidence-driven Microsoft Entra identity inspection engine for understanding **what surrounds an identity and why its security context matters**.

It correlates relationships, permissions, ownership, privilege and PIM context, and other identity signals while keeping observations traceable to the evidence collected. Portable snapshots also enable deterministic offline inspection and comparison.

**PowerShell · Microsoft Graph · Entra ID · Identity Security · Evidence**

Both projects are intentionally **narrow-scoped**. I prefer building focused tools for specific tasks and reusing their scripts and modules when another project needs the same capability.

I am also experimenting with additional Microsoft 365 security tooling, including application identity analysis and broader security assessment automation.
